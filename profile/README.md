# FOWOCO

> **E-9 외국인근로자 HR·행정업무를 구조화하는 AI 업무보조 서비스**

## Project

| 구분 | 내용 |
| --- | --- |
| **소속** | KT AIVLE School AI Track 빅프로젝트 · 수도권 5반 14조 |
| **기간** | 2026.06.29 - 2026.08.14 |
| **주제** | E-9 외국인근로자를 고용한 사업장의 계약·체류·서류·신고 업무 지원 |
| **개요** | AI가 HR 요청과 문서를 분석하고 필요한 절차, 업무카드, 문서 초안을 준비해 담당자의 반복 업무와 누락을 줄이는 서비스 |

## Service

```text
만료일·HR 요청·문서 업로드
→ 업무와 필수정보 분석
→ 서류·유효기간·누락값 확인
→ 업무카드와 문서 초안 생성
→ HR 검토·승인
→ 근로자 안내와 처리 결과 관리
```

- 근로자별 계약·체류·서류 상태와 만료일 통합 관리
- 자연어 요청과 업로드 문서를 활용한 HR 업무 생성
- HWP·HWPX 행정서류 초안 작성과 검토 지원
- 쉬운 한국어·다국어 안내와 근로자 응답 확인
