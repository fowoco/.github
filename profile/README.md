# FOWOCO

**E-9 외국인근로자 HR·행정업무를 구조화하는 AI 업무보조 플랫폼**

FOWOCO는 E-9 외국인근로자를 고용한 사업장의 HR·총무 담당자가 계약, 체류,
서류, 신고 업무를 빠뜨리지 않고 처리하도록 지원합니다. 단순 번역에 머물지 않고
업무를 단계별 Workflow로 관리하며, 필요한 문서 초안과 다음 행동을 준비합니다.

## 핵심 흐름

```text
만료일·HR 요청·문서 업로드
→ 업무 유형과 필요한 정보 분석
→ 필수 서류·유효기간·누락값 확인
→ 업무카드와 문서 초안 생성
→ HR 검토·승인
→ 근로자 안내 또는 기관 제출 준비
→ 결과와 증빙 기록
```

## 주요 기능

- 근로자별 계약·체류·서류 상태와 만료일 관리
- 재계약·연장, 신규등록, 고용변동 업무의 단계별 진행 관리
- 자연어 요청과 업로드 문서에서 필요한 정보 추출
- HWP·HWPX 기반 행정서류 초안 생성과 검토
- 쉬운 한국어·다국어 안내와 근로자 응답 확인
- 승인, 증빙, 감사기록을 포함한 후속 업무 관리

## 설계 원칙

- **AI는 해석과 초안을 보조하고, 규칙은 기한·필수값·상태 전이를 검증합니다.**
- 민감한 안내, 문서 확정, 외부 발송은 HR 담당자의 승인을 거칩니다.
- 기관 사이트에 자동 제출하지 않고, 제출 준비·공식 경로 연결·결과 추적을 지원합니다.
- 개인정보 원문은 모델 학습 데이터와 품질개선 로그에 저장하지 않습니다.

## 현재 개발 범위

현재 MVP는 **재계약·체류 연장**, **신규 근로자 등록**, **고용변동 처리**를 대표
Workflow로 삼아 개발하고 있습니다. 실제 기관 판단과 제출은 담당자가 수행하며,
FOWOCO는 준비 과정의 반복 입력과 누락 확인, 문서 작성, 후속 관리를 줄이는 데
집중합니다.
